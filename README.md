# CSE 391 Assignment 1 — Personal Homepage

## Files
- `index.html`: homepage, personal information, education table, skills, interests, links, footer JavaScript.
- `style.css`: external stylesheet with responsive layout, hover effects, and striped table rows.
- `hobbies.html`: second page for internal navigation.
- `projects.html`: third page for internal navigation.
- `images/profile-placeholder.svg`: local image file; replace it with your own photo.

## Before submitting
1. Replace `images/profile-placeholder.svg` in `index.html` with your own locally stored photo (for example `images/my-photo.jpg`) and update the `src` and `alt`.
2. Replace `your.email@example.com` with your email.
3. Replace the generic Discord link with the actual CSE 391 Discord invite from your instructor.
4. Personalize the quote, interests, education, and project descriptions so they accurately reflect you.
5. Test the links and open the site at desktop and mobile sizes.
6. Validate the HTML/CSS using the W3C validator.

The assignment asks for HTML/CSS but also specifically requires JavaScript to display page location and last-modified date, so a short inline script is included for that requirement.
